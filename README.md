# Fairy of Nail & Lashes
A React + Tailwind CSS salon website designed as an editorial, fairy-inspired scrolling story.

## Stack
- React
- Vite
- Tailwind CSS
- lucide-react

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Main project areas
- `src/App.jsx` — page composition and React components
- `src/components/` — reserved for splitting components further if desired
- `src/data/salonData.js` — salon details, services and image data
- `src/index.css` — custom visual language and animations

## Important: replace demo details
The project contains placeholder contact information and stock/demo image URLs because the supplied Justdial listing did not expose a reliable public photo gallery during project creation.

Update these first in `src/data/salonData.js`:
- phone
- WhatsApp number
- address if needed
- Instagram URL
- service descriptions/prices
- image URLs

The Justdial business listing supplied for reference is included in the Contact section.
