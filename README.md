# Fairy of Nail & Lashes

A React + Tailwind CSS salon website designed as an editorial, fairy-inspired scrolling story.

## Stack

- React
- Vite
- Tailwind CSS
- lucide-react

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Main project areas

- `src/App.jsx` — page composition and React components
- `src/components/` — contains the components which are commonly used in overall application
- `src/pages/` — Each section is divided as component for simplifying the code and stored in this folder
- `src/data/salonData.js` — salon details, services and image data
- `src/index.css` — custom visual language and animations
